## Positioning Guide

Before submitting, know the two lines that anchor everything:

- **Tagline:** Release engine for AI-built software.
- **Hook:** Ship AI-built software without the vibe hangover.

Vibecrafted is NOT a code generator. It is the quality, convergence, and shipping
layer that runs AFTER AI agents produce a repo. This distinction matters on every
platform — most directories are flooded with "AI code generators." Our differentiator
is post-generation: structural mapping, convergence loops, multi-agent orchestration,
and launch-readiness audits.
