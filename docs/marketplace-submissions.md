## 3. Hacker News — Show HN

**Title:** Show HN: Vibecrafted -- Release engine for AI-built software

**Body:**

Hey HN, I built Vibecrafted because every AI coding tool stops at generation. You get a repo that looks like it works, then spend weeks fixing auth held together with tape, god tables, and silent Stripe webhook failures.

Vibecrafted is the release engine you run after AI has produced the code. It forces the repo through:

- Structural mapping (AST-augmented, not grep)
- Convergence loops (priority-weighted denoising until P0=P1=P2=0)
- Install truth (guided browser installer + compact CLI)
- Launch-readiness checks (can a stranger discover, install, trust, and use it?)

It works with Claude Code, Codex, and Gemini CLI. 16 specialized workflows, 4 Rust-based foundations (loctree, aicx, prview, ScreenScribe).

BSL 1.1 -- free for personal use and small teams.
