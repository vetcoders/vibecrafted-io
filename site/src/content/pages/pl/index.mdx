                <p class="section-sub">Poniższa bibliografia rozszerza listę manifestu o wpływy modelowania strukturalnego i konwergencji wyłonione ponownie w wewnętrznej pracy groundingowej AICX.</p>

                    <li class="reference-item"> <p class="reference-citation">Morris, K.; B&ouml;ckeler, B. (2026). <em>Humans and Agents in Software Engineering Loops</em>; <em>Harness Engineering</em>; <em>Context Engineering for Coding Agents</em>. Thoughtworks / Martin Fowler.</p> <p class="reference-note">Framing why-loop / how-loop, projektowanie harnessów i dyscyplina workflow prowadzonego przez człowieka stojące za SHACE i rolą operatora.</p> </li>

(2024). <em>AST-T5: Structure-Aware Pretraining for Code Generation</em>.</p> <p class="reference-note">Wątek pretreningu świadomego struktury stojący za insistencją 𝚅𝚒𝚋𝚎𝚌𝚛𝚊𝚏𝚝𝚎𝚍., że modele nie powinny pisać do repo na ślepo.</p> </li>
                    <li class="reference-item"> <p class="reference-citation">Guo, D. et al. (2021). <em>GraphCodeBERT: Pre-training Code Representations with Data Flow</em>.</p> <p class="reference-note">Komplementarny wynik świadomy struktury, który wzmocnił argument za eksternalizowanym kształtem kodu, mimo że GraphCodeBERT modeluje przepływ danych, a nie AST.</p> <p class="reference-links"><a href="https://arxiv.org/abs/2009.08366">arXiv</a></p> </li>
                    <li class="reference-item"> <p class="reference-citation">Cunningham, W. (1992) i późniejsza literatura o długu technicznym.</p> <p class="reference-note">Konceptualny przodek DoU: działający kod to nie to samo co zdrowy, godny zaufania, gotowy do wysyłki system.</p> </li>

                    <li class="reference-item"> <p class="reference-citation">VetCoders (2026). <em>Manifest 𝚅𝚒𝚋𝚎𝚌𝚛𝚊𝚏𝚝𝚎𝚍.</em> </p> <p class="reference-note">Źródło pierwotne dla SHACE, Marbles, Loctree Mapping, PSCD i założycielskiej Definicji Niezrobionego jako oryginalnych konceptów 𝚅𝚒𝚋𝚎𝚌𝚛𝚊𝚏𝚝𝚎𝚍..</p> <p class="reference-links"><a href="https://github.com/VetCoders/vibecrafted/blob/main/docs/runtime/MANIFESTO_EN.md">Przeczytaj manifest</a></p> </li>
