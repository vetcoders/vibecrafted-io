## What this list is

Vibecrafted is a release engine for software written with AI agents. Not a framework you bolt on. Not a thesis. A discipline for getting AI-built code from "looks done in the repo" to "shipped, secure, and findable in the world." That is the whole product.

_Editorial note (2026-07): this issue is a dated archive. The positioning has since sharpened — Vibecrafted is an orchestration method and runtime for CLI coding agents. The current definition lives on the [homepage](https://vibecrafted.io/en/)._

This list is the operator log for that work. When a cut closes — a plan, a release, a case study — the issue lands here first. No drip campaigns. No "limited-time offers." No FOMO bait. We send when the work is real.

## Who builds this

Two veterinarians who started coding through AI partnership in late 2024. By early 2026 we had shipped enough vibe-coded SaaS rescues to recognise the same four things broken in every codebase. Vibecrafted is what we wrote down so the next operator does not have to learn it on someone else's production.

The framework was built by shipping with it. Three case studies — Loctree LSP, Vista sealed environment, audit-22 parallel-truth — are public at [/showcase](https://vibecrafted.io/showcase/). The reasoning is laid out in [the manifesto](https://vibecrafted.io/manifesto/). The install path is one line: `curl -fsSL https://vibecrafted.io/install.sh | bash`.

## What to expect

One issue per real cut. Length is whatever the cut needs — sometimes a paragraph, sometimes a full post. Always operator-voice. Always cross-linked to the actual commits and reports so you can verify the work yourself.
